# PLACE by sisters – prezentace vizuální identity

Animovaná prezentace návrhu vizuální identity studia PLACE by sisters (tetování, vlasy, kosmetika; Pragovka, Praha 9).

## Jak ji pustit

Stáhni repozitář (**Code → Download ZIP**), rozbal ho a otevři `prezentace.html` v Chrome nebo Edge. Nic se neinstaluje.

## Ovládání

| Klávesa | Co udělá |
|---|---|
| → ↓ mezerník PageDown | dál |
| ← ↑ PageUp | zpět |
| R | znovu od začátku |
| F | celá obrazovka |

Vpravo dole je lišta se stejnými tlačítky. Když se myš nehýbe, sama se schová.

## Poznámky

- Mockupy fasády jsou ilustrační: logo je vložené do fotek okolních cedulí na Pragovce.
- Interiér na pozadí je AI vizualizace podle návrhu architekta, ne fotografie.
- Barevná paleta je návrh.
